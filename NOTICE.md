# Legacy source and attribution

This repository preserves the original Git history, historical source tags and release files of Matko's Titlovi.com Jellyfin plugin (versions 1.x). They remain available, including the [v1.2.5 source tree](https://github.com/Titlovi/titlovi-jellyfin/tree/v1.2.5) and [historical releases](https://github.com/Titlovi/titlovi-jellyfin/releases).

From 2.0 onward, the actively maintained source code for both Jellyfin and Emby is in [Titlovi/titlovi-unified](https://github.com/Titlovi/titlovi-unified), with its own versioned source tags. This distribution repository contains installation documentation, plugin Releases and the existing catalogue, not the 2.x application source.

The original authorship and GPL-3.0 license remain acknowledged. See [LICENSE](LICENSE) and the Unified repository's NOTICE.txt. No historical source tags or release assets should be deleted or rewritten.
