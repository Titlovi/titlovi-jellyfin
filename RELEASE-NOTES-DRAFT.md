## Titlovi.com 2.0.0.0 — Jellyfin 12

This is the first Unified 2.0 release of Titlovi.com for **Jellyfin 12 / .NET 10**, succeeding Matko's original Jellyfin plugin while retaining its existing plugin identity and repository URL.

Search for and download subtitles for films and television episodes directly in Jellyfin.

### What's new

- Jellyfin 12 compatibility, with the original Titlovi.com plugin GUID preserved.
- Shared, actively maintained subtitle-search and archive-handling logic for Jellyfin and Emby.
- Release-aware result ranking without excluding otherwise valid results.
- Optional Serbian, Croatian and Bosnian alternative-language results, with the actual returned language preserved.
- Improved handling of season and series ZIP archives, nested archives and grouped episodes.
- SRT, SUB, TXT, SSA and ASS support, with optional UTF-8 conversion and diagnostic logging.
- One-time import of username and password from the original Jellyfin plugin configuration when new credentials have not already been set. Old tokens are not reused.

### Installation and upgrades

**Recommended:** install/update through the existing Jellyfin plugin repository:

`https://titlovi.github.io/titlovi-jellyfin/repository.json`

The existing plugin GUID and catalogue address are retained. The older 1.x releases remain available for compatible older Jellyfin versions.

**Manual installation:** download **`titlovi-com_2.0.0.0.zip`** from the release assets (not GitHub's autogenerated “Source code” ZIP). Stop Jellyfin, back up the existing plugin and configuration, move the old plugin folder **outside the active plugins directory**, and extract the three files into a dedicated new folder: `Jellyfin.Titlovi.dll`, `meta.json`, `thumb.png`. Do not keep two active copies of the plugin. Preserve existing configuration XML files.

See the [full installation and upgrade guide](https://github.com/Titlovi/titlovi-jellyfin/blob/main/INSTALL.md).

**Requirements:** Jellyfin 12.x and a Titlovi.com account with API access. Upgrading Jellyfin Server itself from 10.11 to 12 is a separate procedure.

### Verification and source

166/166 automated regression tests passed on both Windows and Linux, with successful builds and package checks. A Windows Jellyfin 12 manual installation passed plugin loading, configuration, credentials, movie subtitle downloading and episode subtitle downloading. The new live catalogue-based auto-upgrade has not yet been tested.

Source: [Titlovi.com Unified v2.0.0](https://github.com/Titlovi/titlovi-unified/tree/v2.0.0) · commit `1c4c6dfd04fc0bf51b88a1c8e276896e5f0cab78`

## Titlovi.com 2.0.0.0 — Jellyfin 12

Ово је прво издање обједињене имплементације Titlovi.com 2.0 за **Jellyfin 12 / .NET 10**. Надовезује се на Матков првобитни Jellyfin додатак, уз очување истог идентитета додатка и адресе репозиторијума.

### Новине

- Подршка за Jellyfin 12 уз очување оригиналног GUID-а додатка.
- Заједничка имплементација претраге и обраде архива за Jellyfin и Emby.
- Рангирање према издању видео-снимка, без искључивања других ваљаних резултата.
- Опциони алтернативни резултати на српском, хрватском и босанском језику, уз очување стварног језика титла.
- Побољшана обрада ZIP архива сезона и серија, угнежђених архива и више епизода.
- Подршка за SRT, SUB, TXT, SSA и ASS, уз опциону конверзију у UTF-8 и дијагностичко логовање.
- Једнократни увоз корисничког имена и лозинке из оригиналне конфигурације, ако нови подаци претходно нису подешени. Стари токен се не преноси.

### Инсталација и надоградња

**Препоручено:** инсталирајте или надоградите додатак преко постојећег Jellyfin репозиторијума:

`https://titlovi.github.io/titlovi-jellyfin/repository.json`

**Ручна инсталација:** преузмите **`titlovi-com_2.0.0.0.zip`** међу датотекама издања, а не GitHub-ову аутоматску архиву изворног кода. Зауставите Jellyfin, сачувајте резервну копију додатка и конфигурације, преместите стари директоријум додатка **ван активног директоријума додатака**, па у нови засебни директоријум распакујте `Jellyfin.Titlovi.dll`, `meta.json` и `thumb.png`. Не остављајте две активне копије додатка. Сачувајте постојеће конфигурационе XML датотеке.

Погледајте [детаљно упутство](https://github.com/Titlovi/titlovi-jellyfin/blob/main/docs/sr-Cyrl/INSTALL.md).
